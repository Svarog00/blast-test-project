Описание общей механики игры:
1. Генерируется игровое поле размера N*M. 
2. В каждой ячейке поля находится объект определенного цвета (далее тайл).
3. При клике на тайл, сгорает вся группа прилегающих тайлов того же цвета.
4. После сгорания оставшиеся тайлы опускаются вниз на свободные места.
5. Пустые ячейки вверху поля также заполняются новыми тайлами.
6. Механика «супер-тайла»: если при уничтожении размер группы тайлов больше, чем N, то на месте клетки, по которой был клик, появляется супер-тайл (бомба). По клику на него сгорают все тайлы в радиусе R клеток.

	Цель игры – набрать X очков за Y ходов, иначе проигрыш. Если нельзя сжечь тайл – проигрыш. Значение количества очков и ходов для выигрыша, а также формула начисления очков остается на усмотрение соискателя.

Основное задание:
Механика сжигания и падения тайлов
Подсчет оставшихся ходов и набранных очков
Обработка выигрыша и проигрыша


Руководствоваться принципами ООП и SOLID при разработке
Содержать как можно меньше игровой логики в компонентах
Связь между кор логикой и отображением связывается с помощью событий
Использовать DI вместо статиков и singleton
Запрещено использование физического движка


Моменты для улучшения: использовать фабрику для создания тайлов, чтобы анимация была связана со вью тайла, а не с доской. 
Для фабрики добавить иерархию наследников TileView (например: AnimatedTileView и TileView)
